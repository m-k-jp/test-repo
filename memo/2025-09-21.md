小さな話だが積み重なると効いてくる。

## 背景

代替案も検討したが、運用コストが見合わなかった。設定を一つ変えるだけで挙動が変わる。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

数字で見ると差は明らかだった。

## わかったこと

計測せずに判断しなくてよかった。
