計測してみたら思い込みが崩れた。

## 背景

同じ症状で検索しても出てこなかった。ドキュメントには書かれているが、条件が一つある。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

数字で見ると差は明らかだった。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
