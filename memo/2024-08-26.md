この判断は半年後に効いてくるはず。

## 背景

手元では再現するのに CI では通る、という状態だった。設定を一つ変えるだけで挙動が変わる。

## やったこと

```rust
fn parse(s: &str) -> Result<Config, Error> {
    let c: Config = toml::from_str(s)?;
    c.validate()?;
    Ok(c)
}
```

代替案も検討したが、運用コストが見合わなかった。

## わかったこと

しばらくこの形で運用してみる。
