この判断は半年後に効いてくるはず。

## 背景

原因は思っていたところとは別にあった。設定を一つ変えるだけで挙動が変わる。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

設定を一つ変えるだけで挙動が変わる。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
