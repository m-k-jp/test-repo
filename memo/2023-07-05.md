最初は複雑にしすぎていた。削ったら短くなった。

## 背景

設定を一つ変えるだけで挙動が変わる。数字で見ると差は明らかだった。

## やったこと

```rust
fn parse(s: &str) -> Result<Config, Error> {
    let c: Config = toml::from_str(s)?;
    c.validate()?;
    Ok(c)
}
```

この方式は規模が大きくなると破綻する。

## わかったこと

しばらくこの形で運用してみる。
