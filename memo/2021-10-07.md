この判断は半年後に効いてくるはず。

## 背景

ドキュメントには書かれているが、条件が一つある。原因は思っていたところとは別にあった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

この方式は規模が大きくなると破綻する。

## わかったこと

計測せずに判断しなくてよかった。
