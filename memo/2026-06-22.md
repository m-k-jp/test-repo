三通り試して最後の形に落ち着いた。

## 背景

設定を一つ変えるだけで挙動が変わる。この方式は規模が大きくなると破綻する。

## やったこと

```js
const io = new IntersectionObserver((es) => {
  for (const e of es) if (e.isIntersecting) load(e.target);
}, { rootMargin: '400px' });
```

代替案も検討したが、運用コストが見合わなかった。

## わかったこと

しばらくこの形で運用してみる。
