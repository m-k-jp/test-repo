公式の推奨と現場の使い勝手が食い違った。

## 背景

設定を一つ変えるだけで挙動が変わる。ドキュメントには書かれているが、条件が一つある。

## やったこと

```rust
fn parse(s: &str) -> Result<Config, Error> {
    let c: Config = toml::from_str(s)?;
    c.validate()?;
    Ok(c)
}
```

この方式は規模が大きくなると破綻する。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
