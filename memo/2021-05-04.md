三通り試して最後の形に落ち着いた。

## 背景

数字で見ると差は明らかだった。手元では再現するのに CI では通る、という状態だった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

この方式は規模が大きくなると破綻する。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
