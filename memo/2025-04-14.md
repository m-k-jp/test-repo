先週から気になっていたので調べた。

## 背景

設定を一つ変えるだけで挙動が変わる。数字で見ると差は明らかだった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

この方式は規模が大きくなると破綻する。

## わかったこと

もっと良い方法があれば知りたい。
