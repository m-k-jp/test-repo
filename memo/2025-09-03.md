小さな話だが積み重なると効いてくる。

## 背景

数字で見ると差は明らかだった。原因は思っていたところとは別にあった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

設定を一つ変えるだけで挙動が変わる。

## わかったこと

しばらくこの形で運用してみる。
