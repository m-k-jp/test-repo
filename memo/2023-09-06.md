この判断は半年後に効いてくるはず。

## 背景

この方式は規模が大きくなると破綻する。設定を一つ変えるだけで挙動が変わる。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

代替案も検討したが、運用コストが見合わなかった。

## わかったこと

もっと良い方法があれば知りたい。
