公式の推奨と現場の使い勝手が食い違った。

## 背景

この方式は規模が大きくなると破綻する。設定を一つ変えるだけで挙動が変わる。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

ドキュメントには書かれているが、条件が一つある。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
