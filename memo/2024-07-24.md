三通り試して最後の形に落ち着いた。

## 背景

設定を一つ変えるだけで挙動が変わる。ドキュメントには書かれているが、条件が一つある。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

手元では再現するのに CI では通る、という状態だった。

## わかったこと
