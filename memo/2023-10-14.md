三通り試して最後の形に落ち着いた。

## 背景

この方式は規模が大きくなると破綻する。数字で見ると差は明らかだった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

代替案も検討したが、運用コストが見合わなかった。

## わかったこと
