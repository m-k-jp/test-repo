結論から書くと、想定と違った。

## 背景

設定を一つ変えるだけで挙動が変わる。代替案も検討したが、運用コストが見合わなかった。

## やったこと

```js
const io = new IntersectionObserver((es) => {
  for (const e of es) if (e.isIntersecting) load(e.target);
}, { rootMargin: '400px' });
```

数字で見ると差は明らかだった。

## わかったこと

しばらくこの形で運用してみる。
