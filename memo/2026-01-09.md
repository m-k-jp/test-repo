この判断は半年後に効いてくるはず。

## 背景

設定を一つ変えるだけで挙動が変わる。ドキュメントには書かれているが、条件が一つある。

## やったこと

```ts
export function toSlug(input: string): string {
  return input.trim().toLowerCase().replace(/\s+/g, '-');
}
```

代替案も検討したが、運用コストが見合わなかった。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
