最初は複雑にしすぎていた。削ったら短くなった。

## 背景

設定を一つ変えるだけで挙動が変わる。代替案も検討したが、運用コストが見合わなかった。

## やったこと

```ts
export function toSlug(input: string): string {
  return input.trim().toLowerCase().replace(/\s+/g, '-');
}
```

この方式は規模が大きくなると破綻する。

## わかったこと

もっと良い方法があれば知りたい。
