## 背景

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

原因は思っていたところとは別にあった。
