計測してみたら思い込みが崩れた。

## 背景

手元では再現するのに CI では通る、という状態だった。数字で見ると差は明らかだった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

この方式は規模が大きくなると破綻する。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
