結論から書くと、想定と違った。

## 背景

設定を一つ変えるだけで挙動が変わる。同じ症状で検索しても出てこなかった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

この方式は規模が大きくなると破綻する。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
