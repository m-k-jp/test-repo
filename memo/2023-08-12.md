三通り試して最後の形に落ち着いた。

## 背景

ドキュメントには書かれているが、条件が一つある。代替案も検討したが、運用コストが見合わなかった。

## やったこと

```rust
fn parse(s: &str) -> Result<Config, Error> {
    let c: Config = toml::from_str(s)?;
    c.validate()?;
    Ok(c)
}
```

手元では再現するのに CI では通る、という状態だった。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
