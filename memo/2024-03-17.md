tags: [Astro]
---

結論から書くと、想定と違った。

## 背景

原因は思っていたところとは別にあった。数字で見ると差は明らかだった。

## やったこと

```sql
CREATE INDEX idx_meta ON documents USING gin (meta jsonb_path_ops);
EXPLAIN ANALYZE SELECT id FROM documents WHERE meta @> '{"k":1}';
```

代替案も検討したが、運用コストが見合わなかった。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
