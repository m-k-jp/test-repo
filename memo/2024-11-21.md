三通り試して最後の形に落ち着いた。

## 背景

ドキュメントには書かれているが、条件が一つある。設定を一つ変えるだけで挙動が変わる。

## やったこと

```js
const io = new IntersectionObserver((es) => {
  for (const e of es) if (e.isIntersecting) load(e.target);
}, { rootMargin: '400px' });
```

この方式は規模が大きくなると破綻する。

## わかったこと

結局は基本に忠実なやり方が一番速かった。
