三通り試して最後の形に落ち着いた。

## 背景

設定を一つ変えるだけで挙動が変わる。手元では再現するのに CI では通る、という状態だった。

## やったこと

```rust
fn parse(s: &str) -> Result<Config, Error> {
    let c: Config = toml::from_str(s)?;
    c.validate()?;
    Ok(c)
}
```

代替案も検討したが、運用コストが見合わなかった。

## わかったこと

計測せずに判断しなくてよかった。
