この判断は半年後に効いてくるはず。

## 背景

設定を一つ変えるだけで挙動が変わる。手元では再現するのに CI では通る、という状態だった。

## やったこと

```js
const io = new IntersectionObserver((es) => {
  for (const e of es) if (e.isIntersecting) load(e.target);
}, { rootMargin: '400px' });
```

## わかったこと
