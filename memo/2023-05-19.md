この判断は半年後に効いてくるはず。

## 背景

代替案も検討したが、運用コストが見合わなかった。ドキュメントには書かれているが、条件が一つある。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

原因は思っていたところとは別にあった。

## わかったこと

しばらくこの形で運用してみる。
