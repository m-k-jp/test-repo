## 背景

設定を一つ変えるだけで挙動が変わる。代替案も検討したが、運用コストが見合わなかった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

手元では再現するのに CI では通る、という状態だった。

## わかったこと
