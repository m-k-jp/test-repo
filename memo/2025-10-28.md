公式の推奨と現場の使い勝手が食い違った。

## 背景

設定を一つ変えるだけで挙動が変わる。手元では再現するのに CI では通る、という状態だった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

数字で見ると差は明らかだった。

## わかったこと

計測せずに判断しなくてよかった。
