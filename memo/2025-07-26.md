## 背景

この方式は規模が大きくなると破綻する。原因は思っていたところとは別にあった。

## やったこと

```go
func load(p string) ([]byte, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("load %s: %w", p, err)
	}
	return b, nil
}
```

手元では再現するのに CI では通る、という状態だった。

## わかったこと
