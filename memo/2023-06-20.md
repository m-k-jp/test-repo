三通り試して最後の形に落ち着いた。

## 背景

数字で見ると差は明らかだった。この方式は規模が大きくなると破綻する。

## やったこと

```js
const io = new IntersectionObserver((es) => {
  for (const e of es) if (e.isIntersecting) load(e.target);
}, { rootMargin: '400px' });
```

設定を一つ変えるだけで挙動が変わる。
