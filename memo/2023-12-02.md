公式の推奨と現場の使い勝手が食い違った。

## 背景

設定を一つ変えるだけで挙動が変わる。ドキュメントには書かれているが、条件が一つある。

## やったこと

```js
const io = new IntersectionObserver((es) => {
  for (const e of es) if (e.isIntersecting) load(e.target);
}, { rootMargin: '400px' });
```

原因は思っていたところとは別にあった。

## わかったこと

計測せずに判断しなくてよかった。
